# Teaboom Product Card

Тестовое задание на позицию HTML-верстальщика / Frontend-верстальщика.

## Запуск

Для просмотра проекта достаточно открыть `index.html` в браузере.

Также проект можно запустить через Live Server в VS Code.

## Технологии

- HTML5
- SCSS / CSS
- JavaScript
- CSS Grid / Flexbox

## SCSS

Исходные стили находятся в `style.scss`.
Скомпилированный файл `style.css` уже включен в проект.
